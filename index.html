晏星Agent

大气异常遥感即时监测大模型

这个原型聚焦的是面向大气异常及时监测的遥感智能体主链：用户先从世界底图中截选区域，再给出时间与任务目标，系统随后自主完成数据选择、去云门禁、异常检测、结果解释与下游反演衔接。这里强调的不是工具堆叠，而是“智能体如何自主决定下一步”。

本地视图 展示版 / 研发工作台

核心主链 全球选区到自主监测
当前重点 去云后异常检测
应用方向 星上及时反演

任务输入

场景模板提供区域背景与观测上下文，任务类型决定智能体要解决的问题；系统会围绕这两者自动组织后续流程。

智能体决策

把数据选择、观测质量、主流程和执行策略汇总成一张高层决策卡片。

智能体环路

用感知、规划、执行、反思四个阶段解释当前任务是如何从世界选区走到区域处理结果的。

全球选区入口

先从全球总览底图中圈定感兴趣区域，再交给智能体决定区域尺度、数据链路和异常处理策略。

当前智能体态势

把区域、观测、去云门禁和输出动作收口到同一个摘要层，为汇报和快速演示提供入口。

任务与能力矩阵

把当前智能体支持的数据源、任务类型、模型工具和去云规则放到同一张能力面板里，方便从传统遥感视角理解系统能力边界。

工程迭代看板

把下一步工作拆成小闭环，每次只推进一个可测试模块。

ROI 数据结构与校验

当前只做 bbox / polygon 的规范化校验，为后续检索、推理和切片建立统一契约。

用统一契约把 ROI、时间范围和 collection 送入标准 STAC 搜索接口。

          

          

            

              

                
                
                
                
              

              

                
              

              

            

            

              

              

            

          

        


        

          

            
LAADS 检索与下载器

            
先打通官方 MODIS 气溶胶文件检索，再生成可执行的下载计划，为后续真实数据回放做准备。

          

          

            

              

                
                
                
                
              

              

                
                
              

              

            

            

              

              

              

            

          

        


        

          

            
资产读取统一接口

            
先判断资产是否支持远端窗口读取，再决定走 COG 直读还是先下载到本地，为真正的 patch 读取立契约。

          

          

            

              

                
                
              

              
              

                
              

              

            

            

              

              

            

          

        


        

          

            
模型注册表

            
把当前模型的任务类型、输入约束、运行时依赖和可用状态统一记录下来，避免调度逻辑散落在页面里。

          

          

          

        


        

          

            
云掩膜接入

            
先检索官方 MOD35 / CLDMSK 文件，再判断当前场景是否具备进入定量反演的预处理条件。

          

          

            

              

                
                
                
                
              

              

                
              

              

            

            

              

              

            

          

        


        

          

            
预处理门禁

            
把云掩膜结果、场景云量和辐射质量汇总成可解释的质量门禁，决定是否进入推理或先降级。

          

          

        


        

          

            
推理 Runner

            
根据当前推荐模型和预处理门禁，选择本地推理、静态回放或规则型降级路径。

          

          

            

              

                
              

              

            

            

              

            

          

        


        

          

            
后处理矢量化

            
把当前 ROI 和推理结果转成可回放的 GeoJSON FeatureCollection，为后续切片和缓存做准备。

          

          

            

              

                
              

              

            

            

              

            

          

        


        

          

            
缓存索引与版本化

            
把当前场景、日期、模型版本和矢量结果登记进本地索引，便于后续回放、对比和追溯。

          

          

            

              

                
                
              

              

            

            

          

        


        

          

            
高级预处理链路

            
补齐 Copernicus 高分数据后的三条预处理支路：s2cloudless、Fmask 和重采样对齐。

          

          

            

              

                
                
                
              

              

            

            

          

        


        

          

            
JSON 切片器

            
把矢量结果切成按需加载的 JSON tiles，为回放、局部加载和离线交付做准备。

          

          

            

              
              

                
              

              

            

            

          

        


        

          

            
矢量瓦片交付预览

            
在 JSON 切片稳定后，生成面向 MapLibre/TileJSON 的矢量瓦片交付清单，用于下一步 MVT 化。

          

          

            

              

                
              

              

            

            

          

        


        

          

            
异步预计算队列

            
把大区域、多日期的切片和交付任务放进本地队列，模拟星上或地面异步产物生成流程。

          

          

            

              

                
                
              

              

            

            

          

        


        

          

            
离线评测 Harness

            
用同一套指标快速评估当前链路的预处理质量、推理路径、交付 readiness 和资源收益。

          

          

            

              

                
              

              

            

            

          

        


        

          

            
任务概览

            
汇总当前场景、风险点、观测时刻和星上资源约束。
